# 🧠 Neural Network Visualization Tools

Pedagogical visualization tools for neural networks (Perceptron, MLP, CNN) — M1 research internship (TER), IRIT Laboratory, Université Toulouse III.

## 📌 Description

**Interactive tools** to visualize the inner workings of neural networks, developed during my M1 MAPI3 research internship (TER) at **IRIT** (Institut de Recherche en Informatique de Toulouse, Université Toulouse III).

The project explores how learning mechanisms can be made visible and intuitive, across three levels of model complexity:

- **Perceptron** — visualization of learning convergence
- **MLP (Multi-Layer Perceptron)** — decision boundary visualization
- **CNN (Convolutional Neural Network)** — filter visualization and image reconstruction

## 🎯 Main Contributions

- Design of interactive animations showing perceptron convergence during training.
- Visualization of decision boundaries for multi-layer perceptrons (MLP).
- Development of tools to visualize convolutional filters and image reconstruction in CNNs.
- Pedagogical framing of deep learning mechanisms for teaching / research communication purposes.
